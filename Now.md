# Welcome
Welcome to the */notes* part of my site. The notes viewed here are live synced from my obsidian vault, for those who don't know anything about obsidian. It's basically a note keeping application with lots of different community plugins that for example can be used to distribute markdown files to git, that's how you're seeing this text! The website fetches the text (markdown) file from github every 35 minutes. 

I'm planning on putting stuff here like the songs I'm busy with, some thought fragments, philosophical questions I keep myself busy with through the day and some other stuff as well. Feel free to ask questions about everything you can read here, or what should be added to this part of the site in my guestbook!
